# experiments/

This folder holds quick, exploratory experiments — scripts, notes, and
one-off tests that are not yet ready to be promoted to a full prototype.

## Guidelines

- Each experiment should live in its own sub-folder named with a short
  descriptive slug, e.g. `uart-echo-test/` or `qemu-syscall-hook/`.
- Include a brief `README.md` (or at least a block comment at the top of the
  main file) explaining:
  - What you were trying to find out.
  - How to run it.
  - What you learned / observed.
- Don't worry about code quality here — these are scratch pads.
- If an experiment proves a concept worth pursuing, move refined code to
  `prototypes/` and leave a note here pointing there.
